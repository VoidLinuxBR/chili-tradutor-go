## 1. 概要

`chili-translator-go` は Go で書かれたコマンド ライン ラッパーで、外部翻訳エンジン (`translate-shell` 経由) とディスク上のキャッシュ システムを使用して、異なる形式のファイル (スクリプト、ドキュメント、構造化データ、マニュアル ページ) を同時に複数の言語に翻訳することを自動化し、再翻訳の繰り返しを回避します。

このプログラムは主にソフトウェア プロジェクトをローカライズするために設計されています。`gettext`/`xgettext` を介してソース コードから翻訳可能な文字列を抽出し、`.po`/`.mo` ファイルを生成し、さらに gettext ストリームを経由せずにドキュメント (`.md`、`.txt`、`.json`、`.yaml`、`.html`、man ページ) を直接翻訳します。

## 2. 目的

- 1 つ以上のファイルを構成可能な言語リストに自動的に翻訳します。
- すでに行われた変換 (永続キャッシュ) を再利用することで、ネットワーク呼び出しを最小限に抑えます。
- 従来の gettext ストリーム (「i18n」 アプリケーションで使用する「.po」/「.mo」) とドキュメントとデータの直接変換の両方をサポートします。
- 端末上で進行状況をリアルタイムに視覚的に確認しながら、複数の言語を並行して処理します。
- 手動構成を必要とせずに、ファイルの種類 (拡張子またはシバンによって) を自動検出します。

## 3. 機能範囲

### 3.1 サポートされている入力形式

|拡張子/基準 |タイプが検出されました |翻訳の流れ |
|---|---|---|
| sem 拡張子、com shebang (`#!/usr/bin/env python` など) |スクリプト (Python、php、perl、ruby、javascript、シェル) | gettext (`.pot`/`.po`/`.mo`) |
|拡張子なし、シバンなし |プレーンテキスト |テキストを取得する |
| `.1`から`.9` |マニュアルページ | roff マクロ保護による行ごとの変換 |
| `.sh .py .php .c .cpp .go .pl .rb` |ソースコード | gettext (`.pot`/`.po`/`.mo`) |
| `.html .htm` | HTML |タグ保護付きの行ごとの翻訳 |
| `.md .markdown` |マークダウン |コードブロック保護による行ごとの変換、接頭辞 (`#`、`-`、`1.`) を保持します。
| `.txt` |プレーンテキスト |一行ずつ翻訳 |
| `.json` | JSON |文字列値のマップへの再帰的変換 |
| `.yaml .yml` |ヤムル |再帰的変換 (JSON パーサー経由) |
| `.ポット` |テンプレートの取得テキスト | `pot/` にコピーされ、PO として処理されます。
|他の拡張子 |フォールバック |シェル/gettext として扱われる |

### 3.2 実行の流れ（ファイルごと）

1. ファイルが存在するかどうかを確認します。
2. タイプを検出し (`detectFileType`)、対応する出力ディレクトリ (`pot/`、`doc/`、`txt/`、`json/`、`yml/`、`html/`、`man/`) を準備します。
3. gettext ストリームの場合: `xgettext` を実行して文字列を抽出し、標準化された POT ヘッダー (`stampPotHeader`) を生成します。
4. 翻訳する実際のコンテンツがあるかどうかを確認します (`hasActualContent`)。何もない場合は、空のアーティファクトがクリーンアップされ、警告が表示されてファイルが中止されます。
5. ターゲット言語ごとに 1 つの goroutine をトリガーします。サイズ `jobs` (`-j`、デフォルトは 8) のセマフォによって制限されます。
6. 各ゴルーチンは、形式固有の変換ルーチン (`translateManPage`、`translateHTML`、`translateMarkdown`、`translatePlaintext`、`translateJSON`、または gettext ストリームの `prepareMsginit`/`translateFile`/`writeMsgfmtToMo` トリオ) を呼び出します。
7. 各文字列/行/msgid は `callUniversalTranslator` を介して渡されます。
   - ネットワーク呼び出しの前にローカル キャッシュを正規化し、クエリを実行します。
   - 変数を保護し、翻訳エンジンに送信する前にプレースホルダー、リンク、URL をフォーマットします (`protectVariables`/`restoreVariables`)。
   - 最大 3 回の試行とプログレッシブ バックオフで「trans」 (translate-shell) を呼び出します。
   - 結果をキャッシュ (`~/.cache/chili-tradutor-go/cache.json`) に書き込みます。
8. 進行状況は、端末の複数行領域でカーソルの位置を変更する ANSI エスケープ コードを使用して言語ごとにリアルタイムで表示されます。
9. 各ファイルの最後に、簡単な統計 (時間、キャッシュ ヒット、ネットワーク呼び出し) が表示されます。
10. すべてのファイル (複数の場合) の最後に、全体的な概要が表示されます。

### 3.3 キャッシュシステム

- ローカル: `$HOME/.cache/chili-tradutor-go/cache.json`。
- 構造: `map[言語]マップ[テキスト正規化]CacheEntry{値、最終使用済み}`。
- 最初に 1 回ロードされ (`loadCache`)、通常の実行の最後に 1 回保存されます (`defer` を介して `saveCache`)。
- 「--force」は既存のキャッシュ エントリを無視し、再変換を強制します。
- `--clean-cache` は、30 日以上使用されなかったエントリを削除します。

### 3.4 翻訳不可能なコンテンツの保護

`protectVariables` 関数は、テキストを翻訳エンジンに送信する前にプレースホルダー (`CHILI_REF_N_CHILI`) に置き換えてから、それを復元します (`restoreVariables`)。
- シェルのバリエーション: `$VAR`、`${VAR}`。
- 単純な書式設定指定子: `%s`、`%d` (小文字のみ)。
- 画像のマークダウンへのリンク: `[texto](url)`、`![alt](url)`。
- URL (`http://`, `https://`).)

特定の形式は、「callUniversalTranslator」に委任する前に独自の保護を追加します。
- **マニュアルページ:** roff マクロ (`.` で始まる行) には、翻訳されたマクロの後のテキストのみが含まれます。コメント (`\"`) はそのまま保持されます。
- **HTML:** タグ (`<...>`) は、行翻訳の前にプレースホルダー (`CHILI_HTML_N_CHILI`) に置き換えられます。
- **Markdown:** ``` ``` ``` で区切られたブロックは翻訳されません。タイトル/リスト/番号付け接頭辞は翻訳の外部で保持されます。

### 3.5 セルフテスト (`--self-test')

単純化された一連の内部チェック (依存関係、`protectVariables`/`restoreVariables` のラウンドトリップ) を実行し、OK/FAIL レポートを端末に出力します。

### 3.6 `--self` モード

`chili-translator-go` バイナリから独自の文字列を抽出して翻訳するための特殊モード (`xgettext` を介してソース コード自体から `T`/`TN` 抽出キーワードを使用します)。

## 4. コマンドラインインターフェース

```
chili-tradutor-go -i <arquivo> [opções]
```

|短いフラグ |長い旗 |説明 |標準 |
|---|---|---|---|
| `-i` | `--inputfile` |ソース ファイル (位置引数経由でも複数を受け入れます) | — |
| `-l` | `--言語` |イディオムのリスト (例: `pt_BR,en`) または `all` | `pt_BR,en,es,it,de,fr,ru,zh_CN,zh_TW,ja,ko` |
| `-e` | `--エンジン` |翻訳エンジン: `google`、`bing`、`yandex` | 「グーグル」 |
| `-j` | `--ジョブ' |同時翻訳数 (言語ごとの並列数) | `8` |
| `-s` | `--ソース` |ソース言語 | `自動` |
| `-f` | `--force` |キャッシュを無視し、新しい変換を強制する | `偽` |
| — | `--自分` |バイナリ自体の特殊な抽出 | `偽` |
| — | `--セルフテスト` |整合性セルフテストを実行します。 `偽` |
| — | `--clean-cache` | 30 日間使用されなかったキャッシュ エントリを削除する | `偽` |
| `-q` | `--静か` |サイレント モード (部分的 — 制限事項を参照) | `偽` |
| `-v` | `--冗長` |詳細モード (現在実装されていません) | `偽` |
| `-V` | `--バージョン` |プログラムのバージョンを表示 | — |

「--other language」でサポートされている言語: `ar bg cs da de el en es et fa fi fr he hi hr hu is it ja ko nl no pl pt_PT pt_BR ro ru sk sv tr uk zh_CN zh_TW`。

## 5. 外部依存関係

|バイナリ |パッケージ |使い方 |
|---|---|---|
| `xgettext` |テキストを取得する |ソースコードからの文字列抽出 |
| `msginit` |テキストを取得する |言語ごとの `.po` ファイルの初期化 |
| `msgfmt` |テキストを取得する |コンパイル `.po` → `.mo` |
| `gettext` / `ngettext` |テキストを取得する |プログラムインターフェース自体の翻訳 (`T`/`TN`) |
|トランス |翻訳シェル |外部エンジンによる翻訳実行 |

プログラムは起動時にこれらのバイナリの存在をチェックし (`checkDependency`)、検出されたパッケージ マネージャー (`pacman`、`xbps-install`、`apt`、`dnf`) を介して、`/etc/os-release` で識別されたディストリビューションに従って自動インストールを提供します。

また、実行開始時にインターネット接続をチェックします (`checkInternet`、`8.8.8.8:53` に対する TCP テスト)。オフラインの場合でもキャッシュは参照されますが、キャッシュされていないテキストは翻訳されずに返されます。

|エントリの種類 |出力ディレクトリ |名前のパターン |
|---|---|---|
| gettext (コード) | `pot/`、`usr/share/locale/<lang>/LC_MESSAGES/` | `<pot>.pot`、`<base>-<lang>.po`、`<base>.mo` |
|マニュアルページ | `男/` | `<ベース>-<言語>.<n>` |
| HTML | `html/` | `<ベース>-<言語>.html` |

## 7. 端子出力

- 名前/バージョン、検出されたファイル タイプ、エンジン、ソース言語、ジョブの数、およびキャッシュ パスを含むヘッダー。
- ステータスが「[待機中...]」のターゲット言語の初期リスト。
- 言語別の進行状況バー。ANSI エスケープ コード (`\033[nA`、`\033[K`、`\033[nB`) によってインプレースで更新され、言語、パーセンテージ バー、形式サフィックス (`MD`、`TXT`、`HTML`、`MAN`、`PO`、`JSON`、`OK`) を表示します。
- ファイルごとのクイック統計: 経過時間、キャッシュ ヒット (%)、ネットワーク呼び出し (%)、合計。
- 最終的な概要 (複数のファイルが処理された場合のみ): 合計時間、キャッシュ ヒット、ネットワーク呼び出し、失敗 (ある場合)。
- `github.com/fatih/color` による色の使用: シアン (ハイライト)、緑 (成功)、黄色 (警告/ステータス)、赤 (エラー)、青 (二次情報)。

## 8. 競争

- `sync.WaitGroup` + セマフォ チャネル (`chan struct{}, jobs`) は、ファイルごとに同時に翻訳される言語の数を制限します。
- `sync.Mutex` (`mu`) は、共有キャッシュ マップへのアクセスを保護します。
- `sync.Mutex` (`muConsole`) は、ゴルーチン間のターミナルへの書き込みをシリアル化します。
- 言語完了カウンター (`langsDone`) は `sync/atomic` を使用します。

## 9. 既知の制限事項 (v2.1.20)

- `.yaml`/`.yml` ファイルは `encoding/json` で逆シリアル化され、JSON 構文と互換性のある YAML に対してのみ機能します。
- `translateMap` は配列 (`[]interface{}`) を走査せず、マップのみを走査します。
- HTML の `<script>`/`<style>` ブロックと Markdown のインライン コード スニペット (`` `code` ) は翻訳保護されていません。
- CLI にはフラグ「--verbose」が存在しますが、現在の動作には影響しません。
- 「--quiet」は進行状況バーのみを抑制し、他のヘッダー/概要メッセージは抑制しません。
- 「translate-shell」でサポートされる翻訳エンジン (「google」、「bing」、「yandex」) 以外の翻訳エンジンはサポートされません。
- 手動割り込み時のキャッシュフラッシュのためのシグナル処理 (`SIGINT`/`SIGTERM`) はありません。

## 10. 環境要件

- Go 1.x (ビルド)、Linux システム (サブプロセスでのロケール分離に `/etc/os-release`、`LC_ALL=C` を使用)。
- 翻訳のためのインターネット アクセス (オフライン モードは事前設定されたキャッシュでのみ機能します)。
- `$HOME/.cache/chili-tradutor-go/` および現在の作業ディレクトリ (`pot/`、`doc/`、`txt/`、`json/`、`yml/`、`html/`、`man/`、`usr/` 用) への書き込み権限。
